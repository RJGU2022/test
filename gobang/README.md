# 五子棋人机对弈程序

基于 Python + Pygame 开发的五子棋游戏，支持人机对战。

## 功能特点

- 🎮 黑先白后，人机对弈
- 📊 自动积分系统
- 🏆 五局三胜制
- 🔊 落子音效
- 💡 最优落子提示

## 运行方式

```bash
# 安装依赖
pip3 install pygame numpy scipy Pillow --break-system-packages

# 运行游戏
python3 gobang.py
```

## 操作说明

| 按键 | 功能 |
|------|------|
| 鼠标左键 | 落子 |
| H | 显示最佳落子位置 |
| R | 重新开始整个游戏 |
| N | 开始下一局 |

## 游戏规则

1. 黑方先行
2. 五子连珠获胜
3. 五局三胜制决定最终胜负
